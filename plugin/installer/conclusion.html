Installed

  1. Quit Logic Pro or GarageBand if it was open, then open it again.
  2. Create a new Software Instrument track.
  3. Click the Instrument slot → AU Instruments → Meat Thumb → Meat Thumb.

Not in the list? In Logic: Settings → Plug-in Manager, select Meat Thumb, Reset & Rescan Selection.

To uninstall, delete /Library/Audio/Plug-Ins/Components/Meat Thumb.component.
