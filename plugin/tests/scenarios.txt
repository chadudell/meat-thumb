# Parity scenarios, read by both render_js.mjs and render_cpp.cpp.
#
# Lines before the first `scenario` are a prelude sent at block 0 of every
# scenario (they switch off every source of randomness).
# Inside a scenario: `<block> <command> args...` (a block = 128 frames @ 48 kHz).
# Commands (mirror the UI's port messages):
#   param NAME V | delayParam NAME V | reverbParam NAME V
#   modSlots SRC:DEST:AMT ...        (up to 8 slots; DEST is the JS key)
#   seqStep IDX ACCENT PROB RATCHET NOTES   (NOTES: comma list or '-'; staged)
#   seq BPM SWING GATE LENGTH        (sends the staged steps)
#   seqPlay | seqStop | noteOn NOTE VEL | noteOff NOTE | allOff
